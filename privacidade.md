# Política de Privacidade — Minha Fábrica

## Finalidade

O aplicativo Minha Fábrica utiliza as APIs do Google e do YouTube para auxiliar no gerenciamento de canais autorizados pelos respectivos titulares.

## Acesso aos dados

O acesso às contas ocorre mediante autorização do usuário pelo sistema OAuth 2.0 do Google. As permissões solicitadas devem ser limitadas às funcionalidades necessárias do aplicativo.

## Uso dos dados

Os dados obtidos das APIs do Google devem ser utilizados exclusivamente para as funcionalidades autorizadas pelo usuário, em conformidade com a Política de Dados de Usuários dos Serviços de API do Google.

## Revogação do acesso

O usuário pode revogar as permissões concedidas ao aplicativo a qualquer momento pelo endereço:

https://myaccount.google.com/permissions
